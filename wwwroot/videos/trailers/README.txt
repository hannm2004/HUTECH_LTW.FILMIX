THƯ MỤC TEASER / TRAILER CỤC BỘ
================================

Bỏ file teaser/trailer (.mp4) vào thư mục này.

Sau đó vào Admin > Quản lý phim > Sửa phim, điền ô
"Đường Dẫn Teaser Cục Bộ" theo dạng:

    /videos/trailers/ten_file.mp4

Ví dụ: copy file "breaking_bad.mp4" vào đây rồi điền:
    /videos/trailers/breaking_bad.mp4

Nút "Xem Teaser" trên trang chi tiết phim sẽ phát teaser này.
Nếu để trống ô này, hệ thống tự dùng "URL Trailer" (YouTube) thay thế.
